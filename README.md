# QUIZZILLA - Online Science Quiz System

## Overview
QUIZZILLA is a web-based online quiz platform developed as a Diploma Final Year Project to modernize traditional paper-based assessments in primary education.

The system automates quiz management, grading, and result dissemination while reducing teachers' administrative workload and improving accessibility for students and parents.

## Features
- Online quiz and examination platform
- Automatic grading for objective questions
- Instant result generation
- Teacher quiz management
- Student performance tracking
- Parent email notifications
- Role-based access control
- User management for administrators

## User Roles
### Administrator
- Manage teachers
- Manage students
- Manage classes
- Manage user accounts

### Teacher
- Create quizzes
- Manage questions
- Review student performance
- Send result notifications to parents

### Student
- Answer quizzes online
- View results
- Update profile information

### Parents
- Receive result notifications
- View student performance reports
